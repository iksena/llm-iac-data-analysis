It should also create an SNS topic that emails a specified address, and, for each of fourteen CIS-mandated conditions, a CloudWatch Logs metric filter over the CloudTrail log group paired with a CloudWatch alarm that notifies the SNS topic whenever at least one matching event occurs within a five-minute period; the fourteen conditions to cover are unauthorized API calls, console sign-in without MFA, root account usage, IAM policy changes, CloudTrail configuration changes, console sign-in authentication failures, disabling or scheduling deletion of customer managed KMS keys, S3 bucket policy changes, AWS Config configuration changes, security group changes, network ACL changes, changes to network gateways, route table changes, and VPC changes. The notification email address and the name of the CloudTrail log group should be configurable parameters.
</business_need>
